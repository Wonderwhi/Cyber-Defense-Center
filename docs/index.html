Software Design & Engineering

The Software Design and Engineering enhancement transformed the Cyber Defense Center from an initial application foundation into a structured full-stack security incident management system.

The enhanced application integrates a React frontend with a FastAPI backend and provides incident creation, retrieval, editing, deletion, searching, filtering, sorting, dashboard analytics, and interactive security statistics.

Algorithms & Data Structures

The Algorithms and Data Structures enhancement focused on how security incident information is searched, filtered, sorted, ranked, and summarized.

Incident records are represented using structured objects and collections. The application applies search and filtering logic across incident attributes including severity, status, priority, and category.

Custom ranking logic is used for security classifications such as Critical, High, Medium, and Low so that incidents can be organized according to operational importance rather than alphabetical order.

Skills Demonstrated

  • Searching and filtering
  • Sorting algorithms
  • Conditional and Boolean logic
  • Arrays and structured objects
  • Severity and priority ranking
  • Data aggregation
  • Algorithmic trade-off analysis

Databases

The database enhancement provides persistent storage and structured management of cybersecurity incident information.

SQLAlchemy provides the application's object-relational mapping layer, while FastAPI endpoints allow the frontend to interact with persistent incident records without directly accessing the database.

Incident records contain structured information such as severity, priority, category, status, assignment, reporting information, and timestamps. Complete CRUD functionality allows records to be created, retrieved, modified, and deleted.

Skills Demonstrated

  • Relational database design
  • SQLAlchemy ORM
  • CRUD operations
  • Database queries
  • Schema design and evolution
  • Data integrity considerations
  • Database security considerations
